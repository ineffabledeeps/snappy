Snappy

DB-less full-page screenshots. Send a url or raw html (exactly one) plus optional preset JSON. Returns portable image.base64 / image.dataUrl.

POST /api · GET /api for per-key hints

URL example

{
  "url": "https://example.com",
  "preset": {
    "viewport": { "width": 390, "height": 844 },
    "deviceScaleFactor": 3,
    "isMobile": true,
    "hasTouch": true
  }
}

HTML example

{
  "html": "<!doctype html><html><body style='height:2400px;font:24px sans-serif'>Hello from Snappy</body></html>",
  "preset": {
    "viewport": { "width": 800, "height": 600 }
  }
}

curl

curl -X POST /api \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com"}'

curl -X POST /api \
  -H "Content-Type: application/json" \
  -d '{"html":"<!doctype html><html><body>hi</body></html>"}'
