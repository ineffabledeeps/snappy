Snappy

DB-less full-page screenshots. Pass URL or HTML + preset JSON. Returns portable base64 (optional Cloudinary upload).

POST /api

{
  "url": "https://example.com",
  "preset": {
    "viewport": { "width": 390, "height": 844 },
    "deviceScaleFactor": 3,
    "isMobile": true
  },
  "upload": false
}
